# Console redesign

Mode: Operate. The user explicitly kept the working console first and delegated
visual selection. Configure, Monitor and Review remain standard web controls.

## Direction contract

THESIS: A science-gallery identity around a working experiment console. The
measurements and operator actions lead; no introductory marketing screen.

OWN-WORLD: Cool mineral ground, ink-blue shell and chart ink, copper highlights,
Manrope typography, quiet borders and precise tabular measurements. One original
projected wireframe sculpture supplies spatial depth; it is labelled illustrative.

STORY: Configure a bounded recipe, start its real C++ execution, follow committed
samples and independently observed state, then inspect saved evidence.

FIRST VIEWPORT: Horizontal identity/navigation, a short connection strip, a clear
page title, then a broad recipe editor beside the instrument and launch summary.
Start is beside the recipe preview. On mobile the same regions stack. Pointer
movement rotates the small wireframe sphere; reduced motion holds it still.

FORM: Grounded candidate 4, science-gallery collection graphics; seed b85cfff1.
Other candidates considered: materials catalog, scientific journal, research-campus
wayfinding, technical illustration manual, Swiss research poster, chart atlas.
The split-flap challenger donated consistent data alignment; the timetable
challenger donated firm palette roles. Mascot and cassette forms lost task clarity.
User-delegated selection superseded another visual approval round.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish
review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
